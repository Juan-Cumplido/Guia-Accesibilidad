Implementation

Read this first: the implementation barrier

Custom components, framework abstractions, and late fixes can remove semantics, hide state, or break keyboard and focus behavior. Use native HTML and validated components, then verify them in the real product context.

What to do

Integrate accessibility during implementation

  1. Implement semantic structure, keyboard operation, visible focus, adaptable presentation, and reliable names, roles, states, and values.
  2. Reuse validated components and templates without overriding their accessible contracts.
  3. Use an accessible Definition of Done and return every confirmed defect to a traceable correction cycle.
